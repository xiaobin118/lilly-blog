## 2. 为什么先写线性分类器

多层感知机的最后一层就是一个线性分类器：隐藏层把输入变成一组新特征，输出层对这些特征做线性打分。所以先把"线性打分 + softmax + 交叉熵"这一套写对，后面搭 MLP 时只需要换掉输入特征。

另外，线性分类器是本实验的**对照基线**。不理解它为什么在圆环、螺旋上失败，就无法解释 MLP 到底改进了什么。

## 3. 从特征到打分

有 $N$ 个样本、每个样本 $D$ 个特征、共 $C$ 个类别。记

- $X\in\mathbb{R}^{N\times D}$：每一行是一个样本；
- $W\in\mathbb{R}^{D\times C}$：每一列是一个类别的权重；
- $b\in\mathbb{R}^{C}$：每个类别一个偏置；
- $Z=XW+b\in\mathbb{R}^{N\times C}$：每一行是 $C$ 个类别的打分（logits）。

$Z_{n,c}$ 可以理解为"第 $n$ 个样本属于第 $c$ 类的证据"。它可以是任意实数，不是概率，也不要求和为 1。

一个小例子：$D=2$、$C=4$、$N=3$ 时，`X.shape == (3, 2)`、`W.shape == (2, 4)`、`Z.shape == (3, 4)`。**写代码时每一行都先问自己形状对不对**，这是后面排查反向传播错误最有效的手段。

## 4. softmax：把打分变成概率

### 4.1 公式

对每一行（每个样本）单独做：

$$
p_{n,c}=\frac{\exp(z_{n,c})}{\sum_{j=1}^{C}\exp(z_{n,j})}.
$$

结果满足 $p_{n,c}>0$、$\sum_c p_{n,c}=1$，可以解释为"模型认为样本 $n$ 属于类别 $c$ 的概率"。

### 4.2 三个性质

1. **平移不变**：所有 logits 同时加一个常数 $k$，

$$
\frac{\exp(z_c+k)}{\sum_j\exp(z_j+k)}=\frac{e^k\exp(z_c)}{e^k\sum_j\exp(z_j)}=p_c.
$$

这个性质在第 4.3 节会用来做数值稳定。

2. **保序**：$z_c$ 最大的类别，$p_c$ 也最大。所以 `argmax(p) == argmax(z)`，预测时其实不需要算 softmax。

3. **不会输出 0 或 1**：只要 logits 是有限值，概率就严格在 $(0,1)$ 内。这让交叉熵始终有定义。

### 4.3 为什么不能直接算 exp

如果 $z_{n,c}=1000$，`np.exp(1000)` 会溢出成 `inf`，再除以 `inf` 得到 `nan`。但根据平移不变性，可以先把每行减去该行最大值 $m_n=\max_j z_{n,j}$：

$$
p_{n,c}=\frac{\exp(z_{n,c}-m_n)}{\sum_j\exp(z_{n,j}-m_n)}.
$$

减完之后最大的指数是 $\exp(0)=1$，其余都 $\le 1$，不会溢出，结果和原来完全一样。这就是 TODO 1 的要求。

## 5. 交叉熵：从最大似然到公式

模型给真实类别 $y_n$ 的概率是 $p_{n,y_n}$。独立同分布假设下，整份训练集的似然是

$$
\prod_{n=1}^{N}p_{n,y_n}.
$$

最大化似然等价于最大化对数似然，也等价于最小化负对数似然：

$$
L=-\frac{1}{N}\sum_{n=1}^{N}\log p_{n,y_n}.
$$

这就是平均交叉熵。除以 $N$ 只是让损失的量级与样本数无关，梯度也会相应小 $N$ 倍。

**一个必须记住的基准**：当 $C$ 类完全均匀（所有 $p_{n,c}=1/C$）时，

$$
L=-\log\frac{1}{C}=\ln C.
$$

四类问题就是 $\ln 4\approx 1.386$。自检的第 3 项就是拿全零 logits 验证这个值。后面训练时如果损失一直停在 1.386 附近，说明模型什么都没学到。

从信息论角度，交叉熵 = 真实分布的熵 + KL 散度。训练集固定时熵是常数，所以最小化交叉熵等价于让预测分布逼近真实分布。

## 6. 梯度推导

### 6.1 先对 logits 求导

对单个样本，记 $s=\sum_j e^{z_j}$。先算 softmax 对 $z_c$ 的导数：

$$
\frac{\partial p_k}{\partial z_c}=\frac{\partial}{\partial z_c}\frac{e^{z_k}}{s}=p_k\left(\mathbf{1}[k=c]-p_c\right).
$$

交叉熵里只有真实类别的项含 $z_c$：

$$
\frac{\partial}{\partial z_c}\left(-\log p_y\right)=-\frac{1}{p_y}\frac{\partial p_y}{\partial z_c}=-\frac{1}{p_y}p_y\left(\mathbf{1}[y=c]-p_c\right)=p_c-\mathbf{1}[y=c].
$$

写成向量形式，再对 $N$ 个样本取平均：

$$
\frac{\partial L}{\partial Z}=\frac{1}{N}\left(P-Y\right),
$$

其中 $P$ 是 softmax 输出的 $N\times C$ 概率矩阵，$Y$ 是 one-hot 标签矩阵。**这个式子必须背下来**：它是整条反向传播链的起点，后面 MLP 的输出层用的也是它。

### 6.2 再对 W、b 求导

$Z=XW+b$，所以

$$\frac{\partial L}{\partial W}=X^\top\frac{\partial L}{\partial Z},\qquad
\frac{\partial L}{\partial b}=\sum_{n=1}^{N}\frac{\partial L}{\partial Z_{n,:}}.$$

加入 L2 正则 $L_{\text{reg}}=\frac{\lambda}{2}\lVert W\rVert_F^2$ 后，权重梯度多一项 $\lambda W$；偏置不参与正则。

### 6.3 形状表（写代码时对照）

| 量 | 形状 | 说明 |
|---|---|---|
| `X` | `(N, D)` | 输入 |
| `W` | `(D, C)` | 权重 |
| `b` | `(C,)` | 偏置（广播到每一行） |
| `Z = X @ W + b` | `(N, C)` | logits |
| `P = softmax(Z)` | `(N, C)` | 概率 |
| `dZ = (P - Y) / N` | `(N, C)` | 对 logits 的梯度 |
| `dW = X.T @ dZ (+ l2*W)` | `(D, C)` | 对权重的梯度 |
| `db = dZ.sum(axis=0)` | `(C,)` | 对偏置的梯度 |

检验形状的一个笨办法：`(N,D).T @ (N,C) = (D,C)`，正好等于 `W`。如果你写成了 `dZ.T @ X`，形状会变成 `(C,D)`，一运行就报错——这就是为什么先对形状。

## 7. 决策边界的几何：为什么线性模型有天花板

模型预测类别 $c$ 的条件是：$c$ 的打分不低于其他所有类别，

$$
R_c=\left\{x:\ (w_c-w_j)^\top x+(b_c-b_j)\ge 0,\ \forall j\ne c\right\}.
$$

每个不等式是一个半平面，$R_c$ 是若干半平面的交，所以**一定是凸集**。四类问题有 $4\times3/2=6$ 条两两分界线，把平面切成若干块凸区域。

现在看两份数据：

- **四团高斯**：类别中心在四个角，相邻类别的分界线是直线，四个区域本来就是凸的。线性模型的结构与数据匹配，准确率可以到 98% 左右。
- **四同心圆环**：一个环围住原点，是"中间有洞"的非凸集合。任何凸区域都无法完整包含一个环；无论怎么摆直线，每个扇形区域都会同时切到四个环。四类问题的随机猜测是 25%，线性模型也只能停在 25% 左右。
- **四臂螺旋**：每条臂绕原点旋转，穿过所有角度，同样不是凸集。直线只能从原点向外辐射，把每条臂切成几段。

这就是第 5 步要对比的核心：**不是参数多就更强，而是模型的假设必须能表示真实边界。**

### TODO 1：`softmax(logits)`

- 输入：`(N, C)` 的 logits；输出：`(N, C)` 的概率。

### TODO 2：`cross_entropy(logits, y)`

- 返回 `(loss, dlogits)`，`loss` 是标量，`dlogits` 是 `(N, C)`。
- 推荐用 log-sum-exp 计算损失：先减行最大值 `m`，`logsumexp = log(sum(exp(z-m))) + m`，`loss = mean(logsumexp - z[n, y])`。不要直接 `np.log(p)`，因为概率很小时会变成 `-inf`。
- 梯度：`dlogits = P - onehot(y)`，再除以 `N`。可以用花式索引构造 one-hot，也可以直接 `P[np.arange(N), y] -= 1`。

### TODO 3：`LinearClassifier.loss_and_grads(X, y, l2=0.0)`

- 先 `Z = X @ W + b`，调用 `cross_entropy` 得到 `loss, dlogits`。
- `dW = X.T @ dlogits + l2 * W`，`db = dlogits.sum(axis=0)`。
- 如果 `l2 > 0`，别忘了在 `loss` 上加 `0.5 * l2 * sum(W*W)`。**损失和梯度必须同时加**，只加一边是常见 bug。

## 9. 自检的每一项在验证什么

| 检查 | 验证的内容 | 如果不通过，通常是什么错 |
|---|---|---|
| 1. 行和为 1 | softmax 的归一化是否正确 | 忘了除以和；`axis` 写成了 0 |
| 2. `softmax(z+1000)` | 数值稳定 | 没有减最大值，出现 inf/nan |
| 3. 均匀 logits 的损失 = ln 4 | 交叉熵定义、是否除了 N | 用了 log10；没有取负号；除以了错误的数量 |
| 4. 数值梯度 | 解析梯度是否正确 | 转置、漏乘、L2 只加了一边、忘记除 N |
| 5. 极端 logits | 损失是否在 log 空间计算 | 直接对概率取 log，概率下溢成 0 → `-inf` |

第 5 项对应一个真实的坑。`loss = -mean(log(P[y]))` 在数学上等价于交叉熵，但数值上不安全：如果真实类别的 logit 比别的类别小很多，`exp` 会下溢，`P[y]` 变成精确的 0，`log(0)` 得到 `-inf`，一次更新就会把参数变成 `nan`。正确写法是在 log 空间里算：

```python
m = logits.max(axis=1, keepdims=True)
shifted = logits - m
logsumexp = np.log(np.exp(shifted).sum(axis=1)) + m[:, 0]
loss = np.mean(logsumexp - logits[np.arange(N), y])
```

对 `logits = [[0, 1000, 0, 0]]`、`y = 0`，损失应该是 1000，而不是 `inf`。

第 4 项的原理是**中心差分**：对某个参数 $\theta_i$ 加一个很小的 $\epsilon$ 再减掉，用两次损失差近似导数

$$
\frac{\partial L}{\partial\theta_i}\approx\frac{L(\theta_i+\epsilon)-L(\theta_i-\epsilon)}{2\epsilon}.
$$

它不依赖任何推导，是检验解析梯度的"标准答案"。误差在 $10^{-8}$ 以下说明梯度基本正确；$10^{-3}$ 量级通常意味着某个地方差了一个因子。

## 10. 常见错误清单

1. **`dlogits` 忘记除以 `N`**：损失下降了，但学习率表现得像小了 100 倍。
2. **one-hot 构造错误**：`np.eye(C)[y]` 的形状是 `(N,C)`，没问题；但 `y` 如果不是整数会报错。
3. **`db = dZ.sum(axis=1)`**：得到 `(N,)`，形状错了，应该是 `axis=0`。
4. **`dW = dZ.T @ X`**：形状是 `(C,D)`，和 `W` 对不上。
5. **softmax 不减最大值**：logits 一大就 `nan`，而且不容易复现。
6. **直接 `np.log(P)`**：概率很小的时候 `-inf`，然后损失变 `nan`。
7. **L2 只加在损失里、没加在梯度里**（或反过来）：梯度检查会立刻发现。
8. **学习率太大**：损失震荡或变成 `nan`。先用 0.1 试，确认能下降再调大。
9. **数据没有中心化/缩放**：本步数据在 ±3 以内，问题不大；到了 MNIST 要注意。
10. **把 softmax 的某个分量当成行和**：`P[:, 0]` 是"第 0 类的概率"，不是分母。logsumexp 需要的是 `e.sum(axis=1)`，即 `s`。
11. **损失多了一个负号**：`-mean(log p_y)` 已经由公式里的负号处理过了；用 logsumexp 时写成 `mean(logsumexp - z_y)`，不要再取负。

第 10、11 条有一个共同的陷阱：它们可能让"均匀 logits = ln C"这一项**碰巧通过**。
全零 logits 时 `m=0`、`e=1`、`s=C`、`P[:,0]=1/C`，于是 `log(P[:,0]) = -ln C`；
如果代码里又多加了一个负号，`-(-ln C - 0)` 正好等于 `ln C`。两个错误互相抵消，
但梯度已经不再是交叉熵的梯度，第 4 项数值梯度会立刻把它抓出来。这也是为什么自检要
同时检查"定义"（第 3 项）、"极端值"（第 5 项）和"导数"（第 4 项）——单独一项都可能被巧合骗过。
